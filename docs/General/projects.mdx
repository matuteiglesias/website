## 📒 M.I. Journal (Quartz-Powered Knowledge Hub)

![Journal Screenshot](/img/journal-screenshot.png)

**URL:** [journal.matuteiglesias.link](https://journal.matuteiglesias.link/)

This living digital garden documents my day-to-day development work, strategic thinking, and AI-driven research flows.
Built with Quartz and highly customized for semantic navigation, the journal includes:

- Smart notes exploration and tag filtering
- Embedded project logs and monthly retrospectives

The M.I. Journal is a working memory system and a testament to rigorous self-tracking and content curation. It serves as
a knowledge hub for my ongoing projects, research, and personal development.

## 🌍 Argentina’s Poverty Atlas

![Poverty Atlas Screenshot](/img/poverty-atlas-screenshot.png)

**URL:** [matuteiglesias.link/Pobreza](http://matuteiglesias.link/Pobreza)

This interactive web app delivers an extraordinarily detailed view of social conditions across Argentina, using
high-quality data pipelines and advanced mapping tools. It goes beyond traditional poverty measures, giving policymakers
and researchers richer insights. The project showcases my expertise in data engineering, geospatial analysis, and
visualization.

![Atlas Docs Screenshot](/img/poverty-docs-screenshot.png)

**Docs:** https://matuteiglesias.github.io/atlas-site/

This documentation shows that the poverty measurement stack is a **robust, reproducible methodology** backed by explicit
contracts and QA.

> If you want the interactive product, see the app: **http://matuteiglesias.link/Pobreza**

## 📚 PhD Thesis Online

![Thesis Screenshot](/img/thesis-screenshot.png)

**URL:** [thesis.matuteiglesias.link](https://thesis.matuteiglesias.link/)

This interactive site hosts my PhD thesis, _Essays in the Economics of Aggregation_, transforming a dense academic
document into a browsable, user-friendly format. Built with Docusaurus, it features structured chapters, math rendering,
and dynamic navigation—making complex quantitative research accessible to fellow researchers, students, and
policymakers.

## 🤖 Evaluar App

![Evaluar Screenshot](/img/evaluar-screenshot.png)

**URL:** [evaluar-app.rj.r.appspot.com](https://evaluar-app.rj.r.appspot.com/)

An AI-powered educational platform that enables any course in the department where I work to distribute exercises to
students. It features interactive AI-generated answers and tracks user interactions, providing teachers and students
with real-time feedback and analytics. This demonstrates my ability to build modular, scalable applications that blend
AI, education, and data engineering.
