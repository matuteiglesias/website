## 🧩 Data Infrastructure

1. **Construí un sistema de orquestación de datos end-to-end**: un scheduler modular que supervisa 100+ workflows ETL y ML con logging tipo CI, monitoring y recovery ante fallos.
2. **Diseñé Textflow ETL y arquitectura de memoria**: pipelines JSONL/Parquet que alimentan capas de retrieval basadas en FAISS; incluye data validation, lineage tracking y summarization.
3. **Desplegué ChromaDB como knowledge store**: sistema persistente de embeddings con retraining automático, APIs de consulta y versionado de metadata.
4. **Integré un stack multimodal de datos**: ingestion unificada de audio, video, OCR y texto estructurado en datasets reproducibles y validados por schema.
5. **Automatizé framework para datos financieros**: motor de OCR y parsing que reconcilia facturas y ledgers con trazabilidad de auditoría y dashboards analíticos.

## 🧠 Machine-Learning & Knowledge Systems

6. **Diseñé un engine de entidades y grafo semántico**: pipelines NER → knowledge-graph que potencian analytics cross-document y search.
7. **Implementé un Repository Intelligence Toolkit**: scripts CI y analíticas via GitHub API para dependency audits, code-health metrics y workflow telemetry.
8. **Armé entornos analíticos cloud-linked**: integración con BigQuery y GCP storage para modelado socioeconómico; pulls y transforms automatizados.
