# Professional summary

Senior Data & AI Engineer with a scientific background in economics and physics, focused on building reliable systems for data, documents, models, and automation.

I work across data engineering, machine learning, GenAI, retrieval systems, analytical infrastructure, and applied research. My recent work includes Python and SQL pipelines, LLM/RAG workflows, metadata contracts, validation layers, reproducible data products, and automation systems that transform messy information into usable infrastructure for decisions.

# Skills

**Programming and data**: Python, SQL, R, Pandas, NumPy, scikit-learn, Jupyter
**AI and retrieval**: LLM APIs, RAG, embeddings, ChromaDB, FAISS, LangChain, PromptFlow
**Data engineering**: ETL/ELT, orchestration, JSON/JSONL, metadata contracts, validation, data quality
**Systems and delivery**: FastAPI-style APIs, Docker, GitHub Actions, CI/CD, CLI tools, runbooks
**Cloud and storage**: GCP, BigQuery, SQLite, object storage patterns, managed AI services
**Analytics and research**: statistical modeling, inference, socioeconomic measurement, experiment logging
**Communication and leadership**: technical writing, stakeholder translation, teaching, team coordination
